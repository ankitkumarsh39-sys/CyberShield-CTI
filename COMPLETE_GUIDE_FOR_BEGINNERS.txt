SECTION 1: WHAT IS THIS PROJECT ABOUT?
================================================================================

Imagine you're a security analyst working for a company. Every day, you read 
security blogs and articles that talk about cyber attacks. These articles 
mention:
  - IP addresses of bad servers
  - Dangerous websites (domains)
  - File hashes of malware
  - Links to malicious content

Currently, you have to manually:
  1. Read the article
  2. Find all these indicators
  3. Check each one with VirusTotal (a malware detection service)
  4. Create a blocklist for your company's firewall

This project AUTOMATES all of this!

CyberShield-CTI does:
  ✓ Reads a threat intelligence blog URL
  ✓ Extracts all IOCs (Indicators of Compromise): IPs, domains, URLs, hashes
  ✓ Checks each IOC against VirusTotal API
  ✓ Filters out false positives (legitimate websites)
  ✓ Identifies attack techniques (MITRE ATT&CK framework)
  ✓ Creates a summary and blocklist
  ✓ Saves everything to reports

Result: What would take 30 minutes of manual work now takes 2 minutes!

SECTION 4: KEY CONCEPTS YOU NEED TO UNDERSTAND
================================================================================

CONCEPT 1: IOC (Indicator of Compromise)
─────────────────────────────────────────
An IOC is a piece of technical evidence that shows a compromise/attack happened.
Types of IOCs this project finds:

  1. IP ADDRESS
     Example: 192.168.1.1
     Also defanged: 192[.]168[.]1[.]1
     Why? IP addresses can be owned by attackers and used for attacks
  
  2. DOMAIN NAME
     Example: evil-domain.com
     Also defanged: evil-domain[.]com
     Why? Malware phones home to attacker-controlled domains
  
  3. URL (full web address)
     Example: http://attacker.com/malware.exe
     Also defanged: hxxp://attacker[.]com/malware[.]exe
     Why? Could be a phishing link or malware download location
  
  4. FILE HASH (MD5, SHA1, SHA256)
     Example: d41d8cd98f00b204e9800998ecf8427e (MD5)
     Why? Unique fingerprint of a malware file
  
  5. CVE (vulnerability reference)
     Example: CVE-2024-1234
     Why? Attackers exploit known vulnerabilities

CONCEPT 2: DEFANGING
────────────────────
Threat researchers replace characters in IOCs to prevent accidental clicks:
  
  NORMAL              →  DEFANGED
  ─────────────────────────────────
  http://             →  hxxp://
  https://            →  hxxps://
  .                   →  [.] or (.)
  
Example:
  Original: http://malware-site.com/payload.exe
  Defanged: hxxp://malware-site[.]com/payload[.]exe

Why? So if someone accidentally copies it, their browser won't open it!

This project REVERSES defanging to check IOCs properly.

CONCEPT 3: VirusTotal API
──────────────────────────
VirusTotal is a service that checks if a file/URL/IP is malicious.
It runs the indicator through 70+ antivirus engines.

Example response:
  "This file was flagged as malware by 25 antivirus companies"

Your project queries this API to get a "malicious hits" score.

CONCEPT 4: MITRE ATT&CK Framework
──────────────────────────────────
This is a database of adversary tactics and techniques.

Example:
  ├─ TACTIC: "Initial Access" (how attacker gets in)
  │  ├─ TECHNIQUE: T1566 - Phishing
  │  ├─ TECHNIQUE: T1200 - Hardware Additions
  │  └─ TECHNIQUE: T1199 - Trusted Relationship
  │
  ├─ TACTIC: "Command & Control" (how attacker controls infected system)
  │  ├─ TECHNIQUE: T1071 - Application Layer Protocol
  │  └─ TECHNIQUE: T1008 - Fallback Channels

Your project reads the article and detects which attack techniques were used!

CONCEPT 5: CACHING
───────────────────
Why check the same IOC twice? That wastes API calls and money!

The project saves VirusTotal results to vt_cache.json so it can reuse them.
Example:
  First time: Query VirusTotal for IP 1.2.3.4 → Result: 15 hits
  Second time: Read from cache → Result: 15 hits (instant, free!)

CONCEPT 6: WHITELISTING & BLOCKLISTING
───────────────────────────────────────
Not all IOCs found are malicious. Sometimes legitimate services appear in articles.

  WHITELIST: "Ignore these IOCs" (e.g., google.com is legit)
  BLOCKLIST: "These are definitely malicious" (pre-known threats)

The project checks both before flagging something as dangerous.

Step 5a: Extract IPs
───────────────────
found_ips = sorted(list(set(re.findall(
    r'\b(?:\d{12}|(?:\d{1,3}(?:\[\.\]|\.|\(\.\))){3}\d{1,3})\b',
    page_text
))))

Purpose: Find IP addresses using regex pattern
Pattern explanation:
  \b = Word boundary (start of word)
  \d{1,3} = 1-3 digits (0-255 range for IP octet)
  (?:\[\.\]|\.|\(\.\)) = Either [.] or . or (.) (defanged dot)
  {3} = Repeat 3 times (for first 3 octets)
  \d{1,3} = Last octet
  \b = Word boundary (end of word)

Examples it finds:
  192.168.1.1
  192[.]168[.]1[.]1
  192(.)168(.)1(.)1

Step 5b: Normalize IPs
──────────────────────
def normalize_ip(ip):
    ip = ip.replace("[.]", ".").replace("(.)", ".")
    return ip

Purpose: Convert "192[.]168[.]1[.]1" → "192.168.1.1"

found_ips = sorted(set(normalize_ip(ip) for ip in found_ips))

Step 5d: Extract Domains
────────────────────────
ignored_ext = ['.exe', '.png', '.asar', '.zip', '.txt', '.js', '.json', '.jpg', '.get']

all_domains = sorted(
    set(
        normalize_ioc(d)
        for d in re.findall(
            r'\b[a-zA-Z0-9-]{1,63}(?:\[\.\]|\(\.\)|\.)(?:[a-z]{2,})(?:\/[^\s]*)?\b',
            page_text,
            re.IGNORECASE
        )
        if not any(ext in normalize_ioc(d) for ext in ignored_ext)
    )
)

Purpose: Find domain names
Regex breakdown:
  \b = Word boundary
  [a-zA-Z0-9-]{1,63} = Domain name (letters, numbers, hyphens)
  (?:\[\.\]|\(\.\)|\.)) = Defanged or normal dot
  (?:[a-z]{2,}) = TLD (com, org, net, etc.)
  (?:\/[^\s]*)? = Optional path after domain

Filtering:
  • Ignore .exe, .png, etc. (those are file extensions, not domains)
  • Only keep things that look like domains

Purpose: Find full URLs
Regex looks for:
  • http or hxxp (with optional s)

  • Optional path

Step 6: Process IOCs through VirusTotal
───────────────────────────────────────
def process_ioc(ioc_list, ioc_type, cat):
    for ioc in ioc_list:
        print(f"[*] Checking for {cat}: {ioc[:80]}...")
        
        # Normalize (deobfuscate)
        clean_val = normalize_ioc(ioc, ioc_type)
        clean_lookup = clean_val.lower() if ioc_type in {'url', 'domain', 'hash'} else clean_val
        
        # Check whitelist
        if any(w in clean_lookup for w in self.ip_whitelist + self.domain_whitelist):
            continue  # Skip this IOC (it's legitimate)
        
        # Check manual blocklist
        is_block = clean_lookup in self.manual_blocklist
        
        # Query VirusTotal
        vt_result = (1, "[!] BLOCKLIST MATCH") if is_block else self.get_vt_data(ioc_type, clean_val, force_reanalysis=force_vt_reanalysis)
        hits, status = vt_result
        
        # Categorize as malicious or clean
        if hits > 0 or "\\" in ioc or "hxxp" in ioc.lower() or "[.]" in ioc:
            mal_data[cat].append(entry)  # Malicious
        else:
            clean_data[cat].append(entry)  # Clean (legitimate)

process_ioc(found_ips, 'ip', 'IPs')
process_ioc(all_domains, 'domain', 'Domain')
process_ioc(found_urls, 'url', 'URL')
process_ioc(raw_hashes, 'hash', 'File_Hash')

Purpose: Check each IOC type against VirusTotal and categorize

SECTION 10: TROUBLESHOOTING
================================================================================

PROBLEM 1: "Missing VirusTotal API Key"
────────────────────────────────────────
Error message: ValueError: Missing VirusTotal API Key. Check cyber_shield.log

Solution:
  1. Create .env file in project root
  2. Add line: VT_API_KEY=your_actual_api_key
  3. Make sure no typos in filename (.env, not .ENV)
  4. Save file
  5. Run again

PROBLEM 2: "No module named 'requests'"
─────────────────────────────────────────
Error: ModuleNotFoundError: No module named 'requests'

Solution:
  1. Make sure requirements.txt is in project root
  2. Run: pip install -r requirements.txt
  3. Wait for installation to complete
  4. Run python main.py again

PROBLEM 3: "Connection timeout"
────────────────────────────────
Error: requests.exceptions.ConnectTimeout

Reason: Website took too long to respond (>10 seconds)

Solution:
  1. Check internet connection
  2. Website might be down
  3. Try different URL
  4. Try again later

PROBLEM 4: "404 Not Found" from VirusTotal
────────────────────────────────────────────
Error: HTTP 404 when querying VirusTotal

Reason: IOC format is wrong or API key is invalid

Solution:
  1. Check .env file has correct API key
  2. Make sure API key has no spaces
  3. Check VirusTotal is not blocked by firewall

PROBLEM 5: "Reports folder is empty"
──────────────────────────────────────
After running, no files in reports/ folder

Reason: 
  • No IOCs found in URL
  • URL had only legitimate content
  • Program crashed silently

Solution:
  1. Check cyber_shield.log for errors
  2. Check console output for error messages
  3. Try different URL with malware indicators
  4. Verify IOCs actually exist in webpage

PROBLEM 6: "SSL verification failed"
──────────────────────────────────────
Error: SSLError: [SSL: CERTIFICATE_VERIFY_FAILED]

Reason: Website has SSL certificate issues

Solution:
  • Program auto-retries with verify=False
  • Should work automatically
  • If still fails, might be network/proxy issue
